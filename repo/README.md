# Lingua Quest — Repository Skeleton

This repository skeleton prepares the project structure for the Lingua Quest MVP.

Structure:

- `client/` — Client guidelines & starter notes (Unity or React Native)
- `server/` — Cloud Functions (Firebase) and backend helpers
- `design/` — Figma links, art assets, GDD
- `docs/` — Architecture, schema, deployment notes

Quick start (developer):

1. Install prerequisites: Node.js 16+, Firebase CLI.
2. Clone the project and `cd repo/server/functions`.
3. Run `npm install` and then `npm run build` (or `npm run serve` for local emulation).

This skeleton is intended as a starting point — integrate CI/CD, secrets, and project-specific code next.
